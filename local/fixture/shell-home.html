Synthetic workspace

A local imitation of a Databricks workspace for testing Databricks Cost Companion. Every name, ID and number here is made up.

Pages

  • Jobs & pipelines — list with name links
  • Job {{JOB_101}} runs — run table with a Launched column
  • Pipeline updates
  • Query history
  • SQL warehouses and warehouse size picker
  • Create compute
  • Apps
  • Workspace browser (notebooks)
  • Legacy hash route: #job/{{JOB_101}}/run/{{JOB_101_RUN_D1}}

Fixture controls

The yellow toolbar above the page can replace the <main> element, replace the top navigation, start a continuous DOM mutation storm, and recycle table rows in place like a virtualized list.
