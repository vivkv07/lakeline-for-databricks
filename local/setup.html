Lakeline for Databricks

Connect the browser extension to the local helper

The helper runs only on this computer (127.0.0.1). It signs in to Databricks with the Databricks CLI and runs read-only cost queries for the extension. Sign-in tokens stay with the CLI and the helper; they are never sent to the browser extension.

Pair this helper

  1. Make sure the extension is loaded in this browser (Microsoft Edge or Google Chrome). See Install the extension below if it is not.
  2. Select Connect workspace. The extension checks the helper and opens Connection preferences.
  3. In Connection preferences, choose your workspace, select Sign in with browser, then pick a SQL warehouse and price table.

Open setup again from the start script

This page was opened without its one-time pairing link, or it was reloaded. For safety the pairing key is removed from the address bar as soon as the page opens and is never stored.

Run start-helper.command (macOS) or start-helper.sh again. If the helper is already running, the script reopens this page with a fresh link without restarting the helper.

The extension is not available on this page

This browser did not expose the extension to the setup page. The extension is probably not loaded in this browser yet.

  1. Load the extension (see Install the extension).
  2. Run the start script again. It reopens this page with a fresh link; the running helper is reused.

Using a different browser for the extension? Enter the pairing key manually instead: open the extension's Connection preferences, find Local helper, and paste the key there.

Install the extension

  1. Open edge://extensions in Microsoft Edge or chrome://extensions in Google Chrome.
  2. Turn on Developer mode.
  3. Select Load unpacked and choose the extension folder inside this project.
  4. Run the start script again so this page opens with a fresh pairing link.

Prerequisites for browser sign-in: Databricks CLI v1.12 or newer on this computer. Prefer not to install it? Use a personal access token under Connection preferences instead; the helper is then not needed.
