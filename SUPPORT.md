# Getting help

Lakeline is a free, independent side project. There is no support contract or response-time
guarantee, but these are the best places to ask.

| I want to | Go to |
|---|---|
| Understand a feature or how a number is calculated | The [README](README.md) and the in-extension "How costs work" guide |
| Fix a sign-in or "no permission" problem | The Prerequisites and Troubleshooting sections of the [README](README.md): system-table access and a SQL warehouse that can read them are required for cost features |
| Report a bug | [Open an issue](https://github.com/vivkv07/lakeline-for-databricks/issues/new/choose) with the extension version, browser version and steps. Use Demo mode or the fixture to reproduce, never real data |
| Suggest a feature | [Open a feature request](https://github.com/vivkv07/lakeline-for-databricks/issues/new/choose) |
| Report a security problem | [Private advisory](https://github.com/vivkv07/lakeline-for-databricks/security/advisories/new). Don't open a public issue |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Please don't

- Post access tokens, workspace URLs you don't own, screenshots of real workspaces, or customer data.
- Ask for help with Databricks itself (billing disputes, workspace admin). Contact Databricks
  support for that; Lakeline is independent and not affiliated with Databricks, Inc.
